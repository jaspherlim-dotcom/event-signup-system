# 活动报名系统 · 上线步骤（大约 10 分钟，只做一次）

系统分两部分：

- **前台报名页**：给参加者看的，Google Apps Script 网页应用，免费，手机开就能填，不用登录。
- **后台**：只有你看得到，在 Claude 里（活动跟进后台）。名单、WhatsApp、147 跟进、付款、出席、备忘录、AI 建议都在这里。

两边共用一个 Google Sheet：「活动报名系统（数据库，勿改表头）」，已经在你的 Google Drive 建好。

## 第 1 步：把报名页放进 Google Sheet

1. 打开你的 Google Sheet（表名：活动报名系统，里面要有 Events、Registrations、Feedback、Team、TeamFollow 五个表，第一行是表头）
2. 上面菜单按 **扩展程序 (Extensions) → Apps Script**。
3. 左边会有一个 `Code.gs`，把里面全部删掉，贴上 `frontend-apps-script/Code.gs` 的内容。
   - 想改页面顶部名字，就改 `BRAND`（例如 `'TCC Capital 活动'`）。
   - 想让报名成功页有「WhatsApp 主办方」按钮，就在 `ORGANIZER_WHATSAPP` 填你的号码，例如 `'60123456789'`。
   - **一定要设** `STAFF_PIN`：扫码签到的密码，至少 6 位数字，例如 `'738201'`。只给你和工作人员知道。
4. 左边「文件」旁边按 **＋ → HTML**，名字打 `Index`（不用打 .html），贴上 `frontend-apps-script/Index.html` 的内容。
5. 再按一次 **＋ → HTML**，名字打 `Team`，贴上 `frontend-apps-script/Team.html` 的内容（团队成员登入页）。
6. 按 💾 保存。
7. （可选）想让团队页的「AI 下一步建议」用真的 AI：左边齿轮 **项目设置 → 脚本属性 → 新增**，名称 `ANTHROPIC_API_KEY`，值贴你的 Anthropic API key。费用算在你的 API 账户。不放也可以用，会给内建的基本建议。

## 第 2 步：发布成网页

1. 右上角 **部署 (Deploy) → 新部署 (New deployment)**。
2. 齿轮选 **网页应用 (Web app)**。
3. 执行身份 (Execute as)：**我 (Me)**；谁可以访问 (Who has access)：**任何人 (Anyone)**。
4. 按部署，Google 会要你授权，选你的账号 → Advanced → Go to（不安全）→ Allow。这是你自己写的脚本，所以会出现这个提示。
5. 复制出来的 **网页应用网址**（`https://script.google.com/macros/s/.../exec`）。

## 第 3 步：把网址填进后台

打开后台 → 「设置」→ 报名页网址，贴上，保存。之后每个活动都会自动生成自己的报名链接（网址后面加 `?e=活动ID`）。

## 扫码签到怎么用

1. 每个人报名成功后会看到自己的**入场卡**（带二维码），可以截图或按「用 WhatsApp 发给自己保存」。后台的 WhatsApp 模板也会自动附上 `{ticket}` 入场卡链接。
2. 活动当天，你或工作人员直接用**手机相机**（不用装 app）扫参加者的二维码，会打开签到页。
3. 每支手机第一次要输入 `STAFF_PIN`，之后扫一个签一个：绿色 = 签到成功，橙色 = 已经签过（防止一张卡给几个人用）。
4. 后台「签到模式」每 20 秒自动更新，看得到已签到人数。没带卡的，在签到模式里搜名字手动签。

## 团队推荐怎么用

1. 后台 →「设置」→「团队成员」，填名字和电话按「加入团队」。系统会给他一个推荐代码（例如 AMY01）和 6 位数 PIN。
2. 按「发登入资料」，WhatsApp 把团队登入网址（`网址?team`）、代码和 PIN 发给他。
3. 他登入后，在「推荐链接」拿到每个活动的专属链接（`网址?e=活动ID&r=代码`）和二维码。别人用这个链接报名，就记在他名下（Sheet `Registrations` 的 O 栏「推荐人」）。
4. 成员**只看得到自己带来的人**：名片、WhatsApp、147 跟进、写备注、AI 建议。记录存在 Sheet 的 `TeamFollow` 表。
5. 你在后台看得到全部：名单可以按推荐人筛选；联系人详情会显示推荐人和他的跟进备注；成员记录的联系也算进 147，避免你们重复联系。「数据」有团队排行榜（报名、联系、出席、付款、成交）和 AI 团队建议，每位成员可以写你自己的备注。
6. 有人离开团队，按「停用」：他不能再登入，他的链接也不再记名。

## 同一个网址的几种用法

- `网址?e=活动ID`：直接打开某个活动的报名页
- `网址?e=活动ID&src=fb`：同上，但会记录是从 Facebook 来的（后台「分享 / 二维码」会帮你生成各渠道链接）
- `网址?t=编号&k=凭证码`：参加者的入场卡；`网址?c=编号&k=凭证码`：扫码签到（要密码）
- `网址?e=活动ID&r=代码`：团队成员的推荐链接；`网址?team`：团队登入
- `网址?f=活动ID`：会后问卷（评分、收获、建议、下一步意向），答案进 Sheet 的 Feedback 表

## 以后修改报名页

改了代码后，要按 **部署 → 管理部署 → 编辑（铅笔）→ 版本选「新版本」→ 部署**，网址不会变。

## 147 法则怎么算

首次联系那天 = 第 1 天。第 4 天 = 联系后第 3 天，第 7 天 = 联系后第 6 天。到期会自动出现在后台「今日」，逾期会变红。

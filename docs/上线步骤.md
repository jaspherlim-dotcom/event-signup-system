# 上线步骤（大约 10 分钟，只做一次）

整个系统跑在你自己的 Google 账号里，免费。一个网址三个入口：

| 网址 | 谁用 |
|---|---|
| `网页应用网址?e=活动ID` | 参加者报名、拿入场卡 |
| `网页应用网址?team` | 团队成员登入（推荐链接、自己的名单、147 跟进） |
| `网页应用网址?admin` | 你的后台（只有你，要密码） |

## 1. 准备 Google Sheet

用你现在的「活动报名系统」Sheet 就可以（已经有 Events、Registrations、Feedback、Team、TeamFollow）。
后台第一次用的时候会自动加 CRM、Config 两个表，不用自己建。

## 2. 贴代码

1. 打开 Sheet → 上面菜单 **扩展程序 → Apps Script**。
2. `Code.gs` 全部删掉，贴上仓库 `apps-script/Code.gs`。改上面三个设定：
   - `STAFF_PIN`：扫码签到密码，至少 6 位数字。
   - `ADMIN_PIN`：后台密码，至少 8 位，字母加数字。**只有你知道。**
   - `BRAND`：页面顶部名字，例如 `'TCC Capital 活动'`。
3. 左边「文件」按 **＋ → HTML**，建三个文件，名字分别打 `Index`、`Team`、`Admin`（不用打 .html），各贴上 `apps-script/` 里同名文件的内容。
4. 按 💾 保存。

## 3. 部署

1. 右上角 **部署 → 新部署**，齿轮选 **网页应用**。
2. 执行身份：**我**；谁可以访问：**任何人**。
3. 按部署 → 授权（选你的账号 → Advanced → Go to → Allow）。这是你自己的脚本，所以会出现这个提示。
4. 复制 **网页应用网址**（`https://script.google.com/macros/s/…/exec`）。

打开 `网址?admin`，输入 ADMIN_PIN，就可以开始发布活动了。

## 4.（可选）开 AI

Apps Script 左边齿轮 **项目设置 → 脚本属性 → 新增**：名称 `ANTHROPIC_API_KEY`，值贴你的 Anthropic API key。后台和团队页的「AI 建议」就会用真的 AI，费用算在你的 API 账户。不放也能用，团队页会给基本建议，后台的 AI 按钮会提示没开通。

## 5.（可选）用 GitHub 的短网址

把网页应用网址贴进仓库的 `config.js`（`window.SYSTEM_URL = '…/exec'`），之后
`https://jaspherlim-dotcom.github.io/event-signup-system/?admin` 这类网址会直接带到你的系统。

## 以后改代码

贴上新代码后：**部署 → 管理部署 → 铅笔 → 版本选「新版本」→ 部署**。网址不会变。

## 扫码签到

参加者报名后拿到入场卡二维码。活动当天你用手机相机扫，第一次输入 STAFF_PIN，绿色 = 签到成功，橙色 = 已经签过。

## 147 法则

首次联系那天 = 第 1 天，第 4 天 = 联系后 +3 天，第 7 天 = 联系后 +6 天。团队成员记录的联系也算进去。
